# 用户指南

- 文档类型：用户说明
- 适用范围：ChatBrowserX 0.1 当前实现
- 日期：2026-08-15

## 设置

打开 Side Panel 右上角设置：

- `Codex Access Token`：必填。已保存的值不会重新显示，留空保存表示保持原值。
- `Tavily Key`：仅搜索、网页提取或受控抓取需要。
- 模型：固定显示 `gpt-5.6-terra`，不可修改。
- Reasoning Effort：`low`、`medium`、`high`、`xhigh`。
- 系统提示：追加在内置安全策略之后，不能覆盖权限或确认边界。
- 界面语言：跟随系统、简体中文、English、日本語。

## 网站授权

ChatBrowserX 不默认读取所有网页。第一次在某个网站执行任务、截图或启用选中文本时，点击授权卡片，只授予当前 origin。`chrome://`、Chrome Web Store 和其他浏览器内部页面不支持注入。

跨 origin 导航后需要为新 origin 再授权。授权后页面功能按需注入；同一标签页导航到新 origin 时会重新检查。

## 对话与任务

在输入区描述最终目标，可以同时加入图片。按发送或 `Ctrl/Cmd + Enter` 开始；普通 Enter 换行。

任务卡显示当前状态、已验证浏览器动作数和最近事件。展开后可查看观察、规划、动作和验证边界。运行中可以暂停或取消；暂停、认证失效、标签页丢失等状态会显示继续入口。

Agent 执行点击、勾选、悬停或拖拽时，网页会短暂显示蓝白虚拟光标和点击水波纹；它只用于提示操作位置，不会拦截你的鼠标，也不会出现在截图中。

同一对话同时只允许一个未结束任务。任务处于运行、暂停、待授权、待标签页或待确认状态时，输入区保留草稿但不能再次发送；请先继续、确认或取消当前任务，也可以点击“新建任务”开始独立对话。

提交、发送、删除、付款等高风险动作会展示动作类型与目标摘要。确认只对当前摘要的下一次尝试有效；如果结果不确定，系统不会自动重复高风险动作。

关闭 Side Panel、刷新网页或 MV3 Service Worker 重启不会删除任务。安全状态会从最新检查点自动继续；原标签页被关闭时进入等待，需要在新标签页上明确继续。

## 图片与截图

- 点击“图片”选择 PNG/JPEG/WebP/GIF，或直接粘贴剪贴板图片。
- 每条草稿最多 8 张；单张最多 10 MiB，总计最多 30 MiB。
- 点击缩略图预览，点击 × 移除。
- “截图 → 当前视口”截取当前活动标签页。
- “截图 → 区域截图”先在网页拖拽框选，再完成捕获。

当前版本不做整页滚动拼接、打印、保存 PDF 或 PDF 解析。

## 选中文本

在已授权网页选择文字后会出现轻量气泡：

- “翻译”：中文翻译成英文，其他语言翻译成简体中文；结果可复制。
- “Ask AI”：输入问题后发送到该标签页并打开 Side Panel。当前会话没有未结束任务时继续该会话，否则自动新建独立对话；空问题会按“解释这段内容”处理。

选区最多 8,000 字符；密码框、可编辑区域和扩展自己的 overlay 不会触发。滚动或页面导航会关闭旧气泡。

## 历史和清理

历史按标签页隔离。只有终止状态的当前会话可以清空。清空会删除会话、消息和任务；失去引用且超过 24 小时宽限期的附件会在清理时回收。
