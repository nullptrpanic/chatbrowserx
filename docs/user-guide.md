# 用户指南

## 设置

- `Codex Access Token`：必填。进入设置时加载已保存值，默认隐藏，可点击眼睛查看；保存后仍会展示。
- 模型：固定为 `gpt-5.6-terra`。
- Reasoning Effort：`low`、`medium`、`high`、`xhigh`。
- 系统提示：原样成为 Codex `instructions`，不会追加隐藏前缀。
- 界面语言：跟随系统、简体中文、English、日本語。

## 对话

输入文字后发送，或按 `Ctrl/Cmd + Enter`。每个新任务只发送这次输入；当前页面、旧对话、DOM、任务状态和截图都不会自动加入。

任务运行时可以暂停或取消。认证失效或临时 Provider 错误会出现“继续”入口；继续会从同一条用户消息重新发起完整请求。中断产生的部分回复会标记为已中断，不会冒充完成结果。

当前版本不提供网页浏览、网页操作、搜索或抓取工具。类似“总结当前页面”的请求不会自动获得网页内容；请粘贴内容或主动添加截图。

## 图片与截图

- 支持 PNG/JPEG/WebP/GIF 文件和剪贴板图片。
- 每条草稿最多 8 张；单张最多 10 MiB，总计最多 30 MiB。
- “截图 → 当前视口”捕获活动标签页。
- “截图 → 区域截图”在网页上拖拽选择。
- 截图先进入草稿，只有用户发送后才交给模型。

当前版本不做整页滚动拼接、打印、保存 PDF 或 PDF 解析。

## 选中文本

网页选中文字后可以翻译或 Ask AI。翻译会发送选中文字及有界页面标题/URL；Ask AI 会把选中文字和问题变成明确聊天消息。密码框、可编辑区域和扩展 overlay 不会触发该功能。

## 网站访问权限

所有网站访问权限用于区域截图和划词等用户触发的页面功能。拥有权限不会自动读取或发送网页。Chrome 内部页面和扩展商店页面不支持注入，但仍可使用纯聊天和文件图片。

## 历史和清理

历史按标签页隔离。同一对话只允许一个未结束任务。清空终止会话会删除其消息和任务；失去引用且超过宽限期的附件会在清理时回收。
