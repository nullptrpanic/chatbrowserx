# Translation renderer contracts — acceptance specification

13 个首轮页面、5 次重点复测及 2 项内容补查均已检查实际截图。重试和额外失败不计为首次成功，

## 1. 基线和证据约束

执行遵守 [AGENTS.md](AGENTS.md)、[RUNBOOK.md](RUNBOOK.md) 和
[EVALUATION_STANDARD.md](EVALUATION_STANDARD.md)。复用现有 fixture、原生翻译诊断、
共享 runner 和专用认证 Profile；不添加样例专用认证、权限或另一条执行路径。

当前已有大量未提交修改，HEAD 不能代表实际候选。实施前保存相关源文件、构建散列和工作树
清单，保留上一轮冻结基线及[扩展失败记录](translation-expanded-validation-20260921.md)。
诊断中观察到错误时先保存并分类，再修正其实际所有者，复跑同一用例；不覆盖失败结果。

原生镜框诊断不是 WorkSession benchmark。沿用现有 `e2e/diagnostics/translation-lens.ts`，
其私有截图与诊断证据保留在忽略的 `e2e/.runtime/`。真正的 benchmark 仍使用共享 runner，
结果只进入 `e2e/samples/<id>/benchmark/`。不得把诊断阶段数当作 benchmark 成功数。
标准报告不保存秘密、正文、私有 URL 或原始流量；私有证据不加入 Git。

## 2. 先固定失败，再实施

新用例必须由现有失败事实推导，使用无站点 hostname、私有正文和站点类名的合成结构。
先在未修改产品的基线确认新断言失败；已有正确行为的保护断言也要保留。
若新用例没有复现，需要继续定位真实触发条件，不能对着一个已通过的假复现改产品。

| 共性             | 失败断言与保护断言                                                                                         |
| ---------------- | ---------------------------------------------------------------------------------------------------------- |
| 混合导航共享宽度 | 短译文能在实际可用空间内完整显示；长标题仅按明确约束省略；链接、普通标签、按钮等价；图标不被挤掉           |
| 控件原有尺寸     | 宽搜索控件不因 button 标签变成文字小药丸；既有内容自适应按钮仍正常；输入值和交互不复制                     |
| 行内样式与语序   | 链接、强调、代码背景、padding/边框、图标与原文对应；调换标记顺序、嵌套样式和相邻片段不丢失结构或重复装饰   |
| 空白与示例       | `pre` 原样；非 `pre` 示例缩进/换行不被翻译抹掉；普通 pre-wrap 正文仍可翻译；链接边界不粘字                 |
| 静态媒体与背景   | 图文卡片、祖先背景、图片 object-fit/裁剪完整；文字原文不露出，照片不变白，原生视频/控件像素不被覆盖        |
| 表格与文档       | 普通/合并单元格同行共同定高；横向滚动、部分入框、工具条移动及只读编辑器结构不遗漏普通文字                  |
| 更新与覆盖       | 变短译文露出的内容继续发现；迟到响应、刷新、节点替换不留下旧译文；每个遗漏有可核验阶段，预算终止不伪装完成 |
| 滚动及动态边界   | 实际滚动中复用节点，无扩展造成的长期错位或清空闪烁；源变动只延后最小区域，静态兄弟保留，手动刷新重新采集   |

2026-09-22 V14 复测新增的真实失败：定位容器中的原生搜索建议弹层越出祖先盒子后，
下层翻译副本不得穿透其背景。V15 起 hao123 复测显式启用
`CHATBROWSERX_LENS_FOCUS_TEXT_INPUT=1`，仅聚焦可见文本框并按 ArrowDown 打开建议，
不输入、提交或改写值。合成用例覆盖 relative/fixed 祖先、越界弹层、关闭和缓存重开。
该补充提高原生像素保护覆盖，不放宽原有验收。

V15 飞书首屏复测暴露：临时提示框退出后移除，误将公共应用父容器设为动态边界，导致
静态正文/表格译文全部撤回。补充无站点的静态/动画 Portal 删除与替换回归：静态兄弟
译文必须保留，真正替换的动态分支仍等待手动刷新；空 Portal 的可见后代也必须可刷新。
终态 `unsupported` 或请求成功不能替代这项显示断言。

V16 飞书横滚返回暴露：侧栏中的静态定位透明动画分支被当作整块原生障碍，撤回普通
正文/表格译文。补充透明/不透明固定祖先下的动态分支用例，核验静态正文保留、真实
侧栏文字/背景像素保护、无自动重试及显式刷新。判断仍统一依据实际绘制范围，不按站点定制。

V17 hao123 搜索建议弹层暴露：原有不透明覆盖证明仅接受 fixed 和纯色矩形，导致绝对定位、
渐变背景弹层的普通静态行误判 native-overlap。补充无站点的前景弹层文字与底层原生媒体用例，
同时核验文字覆盖、透明背景保护和未遮挡媒体像素。该遗漏不属于动态或小控件的已批准边界。

截图验证与自动断言共同使用。Range/scrollWidth 可能包含已省略的文字；完整 `textContent`、
元素不越界、字号正常或单一计数都不能独立证明可读。合成用例能容纳的短标签需要逐字可见；
真实页面允许原有长标题省略，但只有一两个字母的菜单不算可用。字体栅格化的小差异不得
被误当故障，真实缺字、遮挡、缩小和错位也不能通过放宽截图阈值掩盖。

V19 的 QQ 复测另暴露固定高度、padding 与 flex-wrap 组合造成的整项裁剪。补充无站点
height/max-height 单行限高、带下边距且居中对齐的链接行：每个原本可见的静态项都须
可读，不能掉到隐藏的第二行或裁掉字的上半部。反向保护自动增高和充足 max-height
容器的自然换行；不要把“源文字碰巧一行”当成固定单行约束。

2026-09-22 用户选择“按推荐的”：固定空间的小控件标签若无法完整显示可读译文，保留该
标签原文，并通过既有部分不支持提示说明；不缩小字号，不改成上下排布。不扩大到普通
标题、正文或表格的静态遗漏：可共享空间的导航继续分配空间，普通长标题仍沿用单行省略。

## 3. 必验实站集合

最终实站目标在首次新候选运行前固定。复用现有同名或同目标样例，准确 ID 由本地目录验证；
样例不存在时依 SAMPLE_SPEC 创建，不臆造可执行的样例名或绕过认证。

| 集合       | 页面与方向                                                       | 需要实际看到的内容                                            |
| ---------- | ---------------------------------------------------------------- | ------------------------------------------------------------- |
| 用户必验   | 飞书 Docx、飞书 Wiki，中→英                                      | 用户反馈过的标题、正文、普通/合并表格及横向滚动；不只检查目录 |
| 用户必验   | 百度，中→英                                                      | 顶部导航、热搜两列、标签/序号、换一换；原有输入内容保留       |
| 用户必验   | QQ，中→英                                                        | 顶部静态新闻区、图文标题、列表、图片与旁边动态视频的边界      |
| 既有回归   | hao123，中→英                                                    | 静态导航/链接网格、浏览器缩放及动态项旁的静态文字             |
| 新失败回归 | 新浪、网易，中→英                                                | 导航实际可读；新浪被覆盖的照片；不同列与图片标题共同布局      |
| 新失败回归 | 菜鸟 HTML 表格，中→英                                            | 正文、上一页/下一页、代码示例缩进；实际滚到渲染表格并核验     |
| 新失败回归 | MDN HTML table、React Quick Start，英→中                         | 行内代码样式、控件尺寸、正文、侧栏、滚动前后静态页头          |
| 额外多样性 | GitHub TypeScript 仓库、Wikipedia 浏览器比较、Hacker News，英→中 | 应用导航/文件列表/README、宽长表格、紧凑新闻列表              |

总计 13 个页面；不将上一轮未跑的三个页面写成已验证。源页面变化时先分类并保存现状，
语义变更按标准更新契约；不能临时换掉失败页面。页面不可访问记为未验证，不满足完成门槛。

## 4. 交互、重复与观察

每个页面跑现有完整交互矩阵：首次翻译、手动刷新、连续滚动返回、滚到下一处再返回、
缓存重开、镜框大小与位置变化、浏览器 125% 缩放及恢复、缩放后刷新、连续三次重开。
文档和表格另需实际嵌套横/纵滚动，不能只检测 DOM 中存在 table。

对每个阶段记录当前源区域、译文实际显示、遗漏归因和请求状态；实际检查关键截图，不把
脚本完成等同于截图通过。每页核验目标、请求、有效结果、实际显示的链路，并独立对照原文，
防止未采集的文字因没有 ID 而被遗漏统计。

全部 13 页在同一冻结候选执行一个完整轮次。首轮通过后，对飞书 Docx、Wiki、百度、QQ、
hao123 再开新页面执行一轮完整交互，保留相同模型和 Profile 初始化规则。最后候选若再次
修改，共享核心受影响的验收结果需在新构建重新取得，不能把多个版本的局部通过拼成全通过。

滚动必须产生真实事件，记录实际匹配的源/副本及歧义数量。不以零样本的零偏移宣称无拖影；
只对可归因的匹配样本作数值结论，并检查连续帧和停止后的显示。浏览器合成线程短暂不同步
需明确报告；持久错位、译文多份残留、整层清空闪烁属于失败。

稳定性结论限于上述矩阵和重复次数，不能声称覆盖任意网页、任意 CSS 或任意网络状态。

## 5. 安全、请求与资源保护

续修验收补充（2026-09-22，首次 V14 实站运行前固定）：新增“单块格式失败→点击重试”
浏览器回归。实站启用 `CHATBROWSERX_LENS_RETRY_FORMAT_ERRORS=1` 时，每个交互阶段最多
追加一次真实点击重试，只用于 `text/TRANSLATION_RESPONSE_INVALID`；保留原失败阶段、
截图、请求和新重试阶段。恢复通过与首次成功分别报告；重复失败、网络错误或布局错误
仍使运行失败，不能靠循环重试取得通过。产品不自动重试，完整刷新快捷键行为不变。

- 源文字、源样式、输入值和编辑器数据不被扩展写入；把页面自身异步变化与扩展写入分开归因。
- 保留水印、原生媒体、图标和静态图片；不能通过隐藏整个原区域来降低截图差异。
- 检查无图片/OCR 输入、无模型工具调用或新权限；链接只来源于原网页，模型结果不作 HTML。
- 上下文继续为目标附近源文字、总计最多 6,000 字符的非指令输入；导航等没有合适锚点时
  允许空上下文，但普通正文用例必须验证实际传入关联上下文及草稿排除。
- 保留请求并发 2、32 块/16,000 字符批次、120 秒超时及现有采集/结构预算。
  不放大预算、每帧全页扫描、自动重试或反复重建来掩盖漏翻。
- 用延迟响应、逆序完成、取消、连续刷新、动态文本更新及失活/重开验证代次与缓存安全。

## 6. 执行门槛与最终报告

先完成窄范围单元和浏览器回归，再执行 EVALUATION_STANDARD 中全部仓库门禁。浏览器测试
需要新构建；随后依 RUNBOOK 执行 doctor、目录校验、必要的交互认证及逐目标 standalone verify。
冻结最终源与构建散列后，串行使用同一个合法专用 Profile 跑上述原生功能诊断。
冻结期间不修改产品或重建。不得复制认证 Profile，亦不得提取凭证。

当前正式门禁为 format:check、lint、test:run、test:e2e、audit:bundle、check:sandbox、
e2e:catalog:validate，另检查 `git diff --check`。`check:codex` 仅在 shell 已合法配置 token
时执行，缺少 token 不绕过认证。门禁具体命令以 EVALUATION_STANDARD 为准。

最终报告必须同时给出：

1. 候选身份、已修复的共同原因、删除和保留的职责。
2. 每项命令及退出状态；已知旧问题与本轮引入问题分开。
3. 每页每轮的通过、失败、未验证状态，关键截图和脱敏诊断证据位置。
4. 动态/原生像素等已批准边界，以及仍未解释的静态遗漏；后者不可算通过。
5. 原文只读、实际可读、原生内容保护和更新稳定性证据。

只有所有必需门禁与本契约的显示、覆盖、安全条件均满足，才能报告完成。有认证、环境或
尚未修复的产品问题时报告阻塞/未完成，不把先前候选计数、HTTP 200 或 ready 状态作为替代。
